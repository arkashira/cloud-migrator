# Partner Targets

## Integration Roadmap

### Phase 1: Immediate (0-3 months)
1. **AWS Migration Hub**
   - **Rationale**: AWS Migration Hub provides a single location to track the progress of application migrations across multiple AWS and partner solutions.
   - **Free-tier limits**: AWS Free Tier includes 1,000 migration task hours per month.
   - **Integration effort**: S
   - **Value-add**: Solves the job of tracking and managing cloud migration tasks across multiple AWS services.

2. **Azure Migrate**
   - **Rationale**: Azure Migrate provides a centralized hub to assess and migrate on-premises workloads to Azure.
   - **Free-tier limits**: Azure Free Tier includes 180 days of free access to Azure Migrate.
   - **Integration effort**: S
   - **Value-add**: Solves the job of assessing and migrating on-premises workloads to Azure.

### Phase 2: Short-term (3-6 months)
3. **Google Cloud Migration Center**
   - **Rationale**: Google Cloud Migration Center provides tools to migrate workloads to Google Cloud.
   - **Free-tier limits**: Google Cloud Free Tier includes $300 credit for new users.
   - **Integration effort**: M
   - **Value-add**: Solves the job of migrating workloads to Google Cloud.

4. **Terraform Cloud**
   - **Rationale**: Terraform Cloud provides a platform for managing infrastructure as code.
   - **Free-tier limits**: Terraform Cloud Free Tier includes 5 team members and 5 workspaces.
   - **Integration effort**: M
   - **Value-add**: Solves the job of managing infrastructure as code for cloud migrations.

### Phase 3: Long-term (6-12 months)
5. **Dynatrace**
   - **Rationale**: Dynatrace provides AI-powered observability and automation for cloud environments.
   - **Free-tier limits**: Dynatrace Free Tier includes 100 GB of data ingestion per month.
   - **Integration effort**: L
   - **Value-add**: Solves the job of monitoring and optimizing cloud environments post-migration.

6. **Datadog**
   - **Rationale**: Datadog provides monitoring and analytics for cloud applications.
   - **Free-tier limits**: Datadog Free Tier includes 5 hosts and basic monitoring.
   - **Integration effort**: L
   - **Value-add**: Solves the job of monitoring and analyzing cloud applications post-migration.

7. **HashiCorp Consul**
   - **Rationale**: HashiCorp Consul provides service mesh and service discovery for cloud environments.
   - **Free-tier limits**: HashiCorp Consul Free Tier includes basic features for small deployments.
   - **Integration effort**: L
   - **Value-add**: Solves the job of managing service discovery and mesh networking in cloud environments.

8. **Puppet**
   - **Rationale**: Puppet provides infrastructure automation and configuration management.
   - **Free-tier limits**: Puppet Free Tier includes basic features for small teams.
   - **Integration effort**: L
   - **Value-add**: Solves the job of automating and managing infrastructure configurations during cloud migrations.
