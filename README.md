# Cloud Migrator – Goal‑to‑Task Mapping Engine

A tiny, pure‑Python library that turns raw migration tasks into cost and effort
estimates and renders a concise ASCII summary chart.

## Features

* **Task estimation** – each task gets an estimated USD cost and person‑days
  effort, applying optional multipliers.
* **Summary chart** – a 40‑character wide bar chart showing total cost and
  effort.
* **STDLIB only** – no third‑party runtime dependencies.
