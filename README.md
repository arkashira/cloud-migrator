# Cloud Migrator

This project generates a technical roadmap for cloud migration, including recommended services, migration phases, and dependencies.

## Usage

1. Install the project using `poetry install`.
2. Run the tests using `pytest`.
3. Use the `generate_roadmap` function to generate a roadmap.
4. Use the `render_gantt_chart` function to render the roadmap as a Gantt chart.
5. Use the `export_to_pdf` function to export the roadmap to PDF.
6. Use the `export_to_csv` function to export the roadmap to CSV.
